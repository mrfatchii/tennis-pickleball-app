# Courtside HK - Tennis & Pickleball Court Booking Platform

A modern web application for booking tennis and pickleball courts in Hong Kong.

## Features

- Browse and search courts
- User authentication
- Court management
- Admin dashboard
- Booking system

## Tech Stack

- React 18
- React Router
- Supabase
- Tailwind CSS
- Cloudflare Pages

## Development

```bash
npm install
npm run dev
```

## Deployment

Automated deployment via GitHub Actions to Cloudflare Pages.

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup instructions.
